# 대본 쓰는 법

게임 스토리는 이 폴더의 `.txt` 파일에 **한국어 문장처럼** 쓴다. 코드는 몰라도 된다.
저장하고 브라우저를 새로고침하면 바로 반영된다. 틀린 곳이 있으면 게임 대신 **몇 번째 줄이 왜 틀렸는지** 화면에 나온다.

- `chapters.txt` — 챕터 순서 (맨 위 = 새 게임 시작 챕터)
- `prologue.txt`, `chapter1.txt` — 각 챕터 대본

---

## 한눈에 보기

```
제목 Chapter 2
부제 9학년

# 첫장면
장소 교실 #2b3a55
타이틀 2.1 / 쌤들한테 찍히기
9학년 첫날. 교실 공기가 뭔가 이상하다.
민준: (불길한 예감이 든다...)
선택
  - 인사하기 (아우라 +5)
      민준: 안녕하세요!
      선생님: ...그래.
  - 무시하기 → 찍힘
아우라 -10, 우울 +5
→ 다음장면

# 찍힘
선생님: 민준, 너 이름 기억했다.
챕터 끝 → chapter3
```

---

## 기본

| 이렇게 쓰면 | 이렇게 된다 |
|---|---|
| `# 장면이름` | 새 장면 시작. 파일의 첫 장면부터 시작한다 |
| `그냥 문장` | 나레이션 |
| `민준: 대사` | 캐릭터 대사 (이름은 10글자까지) |
| `> 메모: 이것도 나레이션` | 앞에 `>`를 붙이면 `:`가 있어도 무조건 나레이션 |
| `// 메모` | 메모 (게임에 안 나옴) |
| `제목 ...` / `부제 ...` | 챕터 이름 (파일 맨 위, 첫 장면 전에만) |

## 화면

| 이렇게 쓰면 | 이렇게 된다 |
|---|---|
| `장소 교실 #2b3a55` | 장소 이름 + 배경색 바꾸기 (색은 빼도 됨 → 이전 색 유지) |
| `타이틀 Day 1 / 전학 첫날` | 화면 전체에 큰 제목 (`/` 뒤는 작은 글씨) |
| `그림 kneel_photo / 벌칙: 무릎 꿇기` | 그림 크게 보여주기 (그림 등록: `src/game/assets.js`) |

배경색은 [색 고르기](https://htmlcolorcodes.com/)에서 `#`으로 시작하는 6자리 코드를 복사하면 된다.

## 스탯

| 이렇게 쓰면 | 이렇게 된다 |
|---|---|
| `아우라 -10, 우울 +5` | 스탯 올리고 내리기 (쉼표나 띄어쓰기로 여러 개) |
| `GPA = 2.0` | 스탯 값을 딱 정하기 |
| `스탯 강화 3` | 스탯 강화 화면 (포인트 3개) |

스탯 이름: `한화`(=`돈`), `아우라`, `거북목`, `우울`, `GPA`(=`학점`)
→ 별명을 더 만들고 싶으면 `src/game/scriptWords.js`에 추가.

거북목이 100이 되면 바로 거북목 엔딩.

## 이동

| 이렇게 쓰면 | 이렇게 된다 |
|---|---|
| `→ 장면이름` | 그 장면으로 이동 (`->` 도 됨) |
| `챕터 끝 → chapter2` | 챕터 결산 화면 → 다음 챕터 |
| `챕터 끝` | 챕터 결산 화면 → 타이틀 (마지막 챕터) |
| `엔딩 dropout` | 엔딩 (목록: `src/game/endings.js` — `turtleNeck`, `dropout`, `expelled`) |

## 선택지

`선택` 줄 아래에 **들여쓰기**하고 `-`로 버튼을 적는다.
버튼 아래에 **더 들여써서** 적은 줄은 그 버튼을 골랐을 때만 나온다.

```
선택
  - 고백하기 (우울 +15, 아우라 -10)
      민준: 저기... 나랑 사귈래?
      엘리아: 너 누구야?
  - 도망가기 → 도망장면
  - 조용히 있기 [잠김: 몸이 말을 듣지 않는다.]
  - 설득하기 [아우라 0 이상] → 설득성공
  - 변호사 고용 [비용 3000]
```

| 버튼 뒤에 붙이면 | 뜻 |
|---|---|
| `(아우라 -10)` | 고르면 스탯 변화 |
| `→ 장면이름` | 고르면 그 장면으로 이동 (없으면 선택지 다음 줄로 계속) |
| `[잠김: 메시지]` | 눌러도 안 눌리는 버튼 (누르면 메시지가 뜸) |
| `[아우라 0 이상]` | 스탯이 모자라면 못 누름 |
| `[비용 3000]` | 한화 3,000을 내고 고름 (돈이 모자라면 못 누름) |

## 미니게임

```
미니게임 배드민턴 상대=김우찬 실력=0.3 점수=3
  이기면 → 이긴장면
  지면 → 진장면
```

결과와 상관없이 같은 곳으로 가려면 `  → 장면이름` 한 줄만 쓴다.
`이기면/지면` 줄을 안 쓰면 미니게임이 끝난 뒤 다음 줄로 계속한다.
값에 띄어쓰기가 있으면 따옴표로 묶는다: `상대="KISAC 1라운드"`

| 미니게임 | 설정 |
|---|---|
| `QTE` | `횟수=6` `성공=4` (6번 중 4번 성공하면 승리) |
| `배드민턴` | `상대=이름` `실력=0~1` (0.6 넘으면 민준보다 잘함) `점수=11` (한 게임 점수, 2점 차) `세트=3` (3판 2선승) `조작=예` (상대가 절대 안 놓침) |
| `재판` | `판사=볼란드` `목숨=3` `질문=질문목록이름` `제한시간=12초` |
| `러너` | `시간=25초` |

### 시험 (formative / summative)

```
formative 수학
summative 중간고사 문제수=4
summative 기말고사 문제=에임,강타,기억
  이기면 → 잘봄
  지면 → 망함
```

- `formative`는 쪽지시험 (기본 2문제, GPA 최대 ±0.1), `summative`는 큰 시험 (기본 5문제, GPA 최대 ±0.3)
- 첫 단어 뒤는 과목 이름 (화면 제목에 나옴)
- 문제는 미니게임 12종 중 랜덤. 직접 고르려면 `문제=에임,강타`
  - `초록불` `에임` `파리` `비트` `강타` `막타` `기절` `스킬콤` `색깔` `기억` `피하기` `연타`
- 평균 점수로 1~7등급, 4등급 이상이면 `이기면` 쪽으로 간다. GPA는 자동으로 바뀐다.

### 우울하면 미니게임이 어려워진다

Depression이 높을수록 모든 미니게임(시험 포함)이 어려워진다. 100%면 시간 40% 감소 / 속도 40% 증가.
그래서 "밤새 공부(GPA+, 우울+)" vs "게임하고 자기(우울-)" 같은 선택에 의미가 생긴다.

### 재판 질문 목록

파일 아무 곳에나 `# 질문 목록 이름`으로 만든다. `*`가 정답, `-`가 오답.

```
# 질문 목록 볼란드재판
? 수업 시간에 몰래 폰 게임을 했다는 제보가 들어왔다.
  - 전 그런 적 없습니다.
  * 증거 있습니까?
  - ...제보자가 누구죠?
  틀리면: 거짓말과 협박은 감점이다, fella.
```

## 새 챕터 만들기

1. 이 폴더에 `chapter2.txt`를 만든다.
2. `chapters.txt`에 `chapter2` 줄을 추가한다.
3. 이전 챕터 마지막을 `챕터 끝 → chapter2`로 바꾼다.

## 자주 하는 실수

- 선택지 버튼을 **들여쓰기 안 함** → `선택` 아래 줄은 띄어쓰기 2칸 이상 앞에 넣기
- 나레이션에 `:`가 있어서 대사로 나옴 → 줄 앞에 `>` 붙이기 (`> 벌칙: 무릎 꿇기`)
- `→ 장면이름` 오타 → 오류 화면에 어느 줄인지 나온다
- 이미 플레이 중인 세이브는 장면 이름을 바꾸면 이어하기가 안 될 수 있음 → 새 게임으로 확인
