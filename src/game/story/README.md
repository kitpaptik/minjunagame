# 스토리 스크립트 작성법

챕터 파일은 `nodes` 객체를 가진다. 각 노드는 스텝 배열이고, 위에서 아래로 실행된다.

| 스텝 | 설명 |
|---|---|
| `{ scene: '교실', bg: '#2b3a55' }` | 배경 색 + 장소 이름 변경 |
| `{ title: 'Day 1', sub: '전학 첫날' }` | 화면 전체 타이틀 카드 |
| `{ text: '...' }` | 나레이션 |
| `{ say: '세하', text: '...' }` | 캐릭터 대사 |
| `{ choice: [ ...옵션 ] }` | 선택지 (아래 참고) |
| `{ add: { aura: -10 } }` | 스탯 증감 |
| `{ set: { gpa: 2.0 } }` | 스탯 값 지정 |
| `{ cg: '이미지키', caption: '...' }` | 이미지(CG) 전체화면 표시. 이미지가 없으면 자리표시 박스 |
| `{ upgrade: 3 }` | 스탯 강화 화면 (포인트 3개) |
| `{ minigame: 'qte', config: {...}, win: '노드', lose: '노드' }` | 미니게임 실행 후 결과에 따라 이동 |
| `{ goto: '노드' }` | 다른 노드로 이동 |
| `{ chapterEnd: '다음챕터id' }` | 챕터 결산 화면 (null이면 타이틀로) |
| `{ ending: '엔딩id' }` | 엔딩 (src/game/endings.js) |

선택지 옵션:

```js
{ label: '나대기', add: { aura: -10 }, reply: [{ say: '민준', text: '...' }], next: '노드' }
{ label: '조용히 있기', disabled: '몸이 말을 듣지 않는다...' }  // 눌러도 안 눌리는 버튼
{ label: '설득하기', requires: { aura: 0 } }   // Aura 0 이상이어야 선택 가능
{ label: '변호사 고용', cost: 3000 }          // 한화 3,000 지불 (부족하면 선택 불가)
```

- `reply`: 선택 직후 실행할 스텝들 (선택)
- `next`: 이동할 노드. 없으면 선택지 다음 스텝으로 계속
